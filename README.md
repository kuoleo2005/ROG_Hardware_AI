# 電腦硬體 AI 顧問 v1.0.1

Windows 桌面版電腦硬體檢測、跑分估算、升級建議與 AI 顧問工具。
主要目標是讓電腦小白也能快速看懂自己的電腦效能、適合玩什麼、哪裡需要升級，以及該不該直接買新機。

---

## 主要功能

### 硬體檢測

可偵測並顯示：

* CPU
* RAM / 已使用記憶體
* GPU
* VRAM / 已使用顯示記憶體
* 磁碟容量與使用量
* 部分主機板 / 筆電資訊
* 部分散熱與風扇資訊

> 注意：部分硬體資訊會受 Windows 權限、驅動程式、筆電廠商限制影響，若系統無法讀取，程式會以推測或提示方式呈現。

---

### 硬體評價

程式會將硬體分成四種方向評分：

* 遊戲評價
* 生產力 / 剪輯評價
* AI 評價
* 綜合評價

評級採用：

```text
SSS > SS+ > SS > S+ > S > A++ > A+ > A > B++ > B+ > B > C > D > E > F
```

評分會參考 CPU、GPU、VRAM、RAM、SSD 等因素，並依照用途做加權。

---

### 簡短評價

程式會用較白話的方式描述目前電腦大概適合：

* 1080p 遊戲
* 2K 遊戲
* 4K 遊戲
* 剪輯 / 多工
* AI 入門或進階用途

例如：

```text
1080p / 2K 中高畫質可用，4K 需降畫質或關閉光追。
剪輯與 AI 入門 / 中階可用，大模型與長影片建議雲端輔助。
```

---

### 升級建議

程式會依照目前硬體狀態給出升級方向，例如：

* RAM 是否需要升級
* SSD 是否需要補容量
* 筆電是否只能升級 RAM / SSD
* 桌機是否可考慮 GPU、電供、散熱、平台升級
* 老舊硬體是否建議直接換新機

若判斷設備過舊、無獨立顯卡，或升級效益太低，程式會傾向建議更換整機，而不是盲目升級。

---

### 圖表分析

目前支援：

* 硬體能力雷達圖
* 瓶頸分析圖

用來輔助判斷 CPU、GPU、RAM、SSD 哪一項可能拖累整體表現。

---

### AI 顧問

內建結構化 AI 顧問，可根據使用者輸入的需求回答，例如：

```text
我想玩 2K 遊戲，預算 3 萬，該升級還是買新機？
```

AI 會參考目前硬體評價、用途、預算與升級限制，給出較白話的建議。

---

### 智慧清單 / 購物車

支援將選擇的零組件加入智慧清單，方便整理升級或新裝機需求。

目前可加入：

* CPU
* GPU
* RAM
* SSD
* 螢幕
* 其他零組件

## v1.0.1 更新重點

* 修復「查詢時價 / 查詢商品」流程。
* 修復「確定加入清單」按鈕，查價成功後可加入智慧清單。
* 購物車摘要固定移到操作面板下方。

---

## 已知問題

* 搜尋特定商品功能目前仍處於開發階段，預計 v1.1.0 完整加入。
* 查詢商品 / 即時查價功能目前為測試階段，價格、庫存、平台比對仍可能不精準。
* 部分筆電或品牌套裝機可能無法完整讀取主機板、電供或散熱資訊。
* 部分防毒軟體可能會對未簽章的 exe 顯示提醒。

---

## 注意事項

* 購物與價格資訊仍以實際電商網站為準。
* 硬體評分為估算結果，不等同實際跑分。
* AI 建議僅供參考，實際購買前仍建議確認規格、保固、庫存與相容性。
* 本工具仍屬研發版本，不代表最終品質。

## 使用方式

### 一般使用者

直接下載 Release 裡的 `.exe` 後執行：

```text
ROG_Hardware_AI_v1.0.1.exe
```

如果 Windows 出現 SmartScreen 提醒，可點選：

```text
其他資訊 → 仍要執行
```

這是因為目前程式尚未進行正式數位簽章。

---

### 開發者 / 原始碼執行

如果想用 Python 執行原始碼，請先安裝套件。

建議環境：

```text
Python 3.11 或 Python 3.12
Windows 10 / Windows 11
```

安裝套件：

```bash
python -m pip install -U pip
pip install -r requirements.txt
```

執行：

```bash
python ROGApp_v1_0_1_release.py
```
